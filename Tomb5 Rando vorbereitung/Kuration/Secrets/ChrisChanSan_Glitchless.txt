# Secret-Liste fuer den TR5 Randomizer.
#
# Dateiname = Autor_Kategorie.txt - der Autor erscheint so im Dropdown der
# jeweiligen Kategorie (Glitchless oder Glitched). Wer eine eigene Liste
# beisteuern will, legt einfach eine weitere Datei in diesen Ordner.
#
# Spalten:
#   Level             Dateiname des Levels
#   Anzahl            wie viele Secrets das Level hat (Gegenprobe)
#   Type_ID           223 = Secret
#   Level_ID          die Item-Indizes der Secrets im Vanilla-Level
#   New_Rooms/Sektor  wohin sie sollen, in derselben Reihenfolge wie Level_ID.
#                     Leer = dieses Level bleibt vanilla.
#   Extra_Options     zusaetzliche Items und Trigger. Mehrere Gruppen mit ";"
#                     trennen (eindeutig); das alte "+" wird weiter gelesen.
#                     Was der Leser nicht versteht, meldet er - ein vertipptes
#                     "@Angel0" verschwindet also nicht stillschweigend.
#
#                     Aufbau einer Gruppe - drei Formen:
#
#                     1) Item anhaengen
#                        add Type_ID(<Typ>)@Room<N>(x<A>,z<B>)
#                        Statt Raum+Sektor geht auch die Stelle eines
#                        vorhandenen Items:  @LikeItem(<Item>)
#                        dazu wahlweise:
#                          @OCB(<Wert>)     Objektcode - bei Schaltern legt er
#                                           fest, wo Lara stehen muss!
#                          @Angle(<Grad>)   Klammern optional
#                          @Height(<Wert>)  so viele Einheiten HOEHER
#                          @XOff(<Wert>)   Versatz in X, @ZOff(<Wert>) in Z
#                          Trigger_Type(Key|Switch|Pickup)to->... Item_Level_ID(<Ziele>)
#
#                     2) Nur ein Trigger, ohne Item
#                        add Trigger_Type(Trigger)@Room<N>(x<A>,z<B>)to->... Item_Level_ID(<Ziele>)
#
#                     3) Ein vorhandenes Item umtypen (Position bleibt)
#                        replace Item_Level_ID(<Item>)with->Type_ID(<neuerTyp>)
#                        dazu wahlweise @OCB(...), @Angle(...), @Height(...),
#                        @XOff(...) und @ZOff(...)
#
#                     Item_Level_ID nimmt MEHRERE Ziele, mit Komma getrennt.
#                     Ein Ziel ist entweder ein vorhandener Itemindex oder
#                     "Neu<k>" - das k-te Item, das diese Zeile selbst anlegt.
#                     Damit laesst sich ein gerade erzeugtes Item ansteuern,
#                     dessen Index man beim Schreiben noch nicht kennen kann.
#
#                     Beispiel Doppeltuer, ein Schalter fuer beide Haelften:
#                       (replace Item_Level_ID(13)with->Type_ID(284)@Angle90)
#                       ; (add Type_ID(284)@LikeItem(13)@Height(1024)@Angle90)
#                       ; (add Type_ID(266)@Room202(x1,z1)@Angle270
#                          +Trigger_Type(Switch)to->Door Item_Level_ID(13, Neu1))
#
#                     Das "+" VOR Trigger_Type gehoert zur Gruppe und bleibt.
#
# Die Hoehe wird nicht angegeben - der Randomizer rechnet die Bodenhoehe des
# Sektors selbst aus, auch auf Schraegen.
