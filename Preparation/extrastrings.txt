# extrastrings.txt - the engine's own words in French, German, Italian and
# Spanish
#
# What it is: the options pages, the F4 outfit window, the Credits screen
# and the key bindings show words of their own that the game's language
# files do not have. The engine carries a translation of every one of them;
# a word in this file takes its place, so a player or a translator can
# change a word without building the engine. The words below are the
# engine's own, so this file as it is changes nothing.
#
# Where it goes: into the game folder, next to the game's executable and
# SCRIPT.DAT. The engine reads it once at start, so an edit shows at the
# next start. Without the file the engine uses its own words.
#
# The format: plain text, UTF-8 with or without a byte order mark, Windows
# or Unix line ends, at most 64 KB. A line starting with # is a comment, and
# blank lines are skipped. [French], [German], [Italian] and [Spanish] open
# a section, in any case; any other section is skipped with its lines.
# Inside a section a line reads
#
#     English text=word
#
# for example "Language=Langue" in [French]: the text exactly as the engine
# shows it in English, an equals sign, and the word in that language.
# Spaces around the equals sign are ignored; the text and the word may hold
# spaces. When a text appears twice in a section, its last line counts. A
# line without an equals sign or with nothing after it is skipped, and so
# is a word of more than 63 bytes.
#
# The game's font draws the small accented letters of these four languages
# and of the capitals only these: Ä Â Á É Ö Ó Ü Ñ, with ¿ and ¡. Write any
# other capital without its accent: the font leaves such a letter out. A
# sign such as « or § and a letter outside Latin-1 show as "?".
#
# English and US English show the English text, and so do Japanese and
# Dutch. Started with -log, the engine writes one line on what it read:
# STRINGS file=extrastrings.txt found=1 keys=... skipped=0 rejected=0.
