Special Thanks to all of these awesome people. All of these made It possible to build this randomizer.

Tomb5 Decompile: https://github.com/Trxyebeep/TOMB5
  Troye (Trxyebeep), ChocolateFan, thatguyfrombb and Raildex. The credits
  screen in the game and README.md both name all four, and their code is
  in every binary built here.

tomb3 Decompile: https://github.com/Trxyebeep/tomb3 (Trxyebeep) - the TR3 enemies (T-Rex, Raptor, Compy, Vulture) come from there

TROne (GPLv3): https://github.com/todesengel1931 (Todesengel1931) - the
  HD-at-run-time path carries his code, and the modern control scheme
  carries his design and his test expectations. Twenty-seven source files
  here name his copyright beside ours; THIRD-PARTY.md lists what was taken,
  file by file. He is in the contributors list below as well, because he
  played and reported too.

Trview: https://github.com/chreden/trview (Chreden)

TRmod https://b122251.org/tr/tools/index.html (b122251)

TR Viewer: http://www.evpopov.com/ https://web.archive.org/web/20020320131858/http://www.evpopov.com/index2.html (E.Popov)

imgui: https://github.com/ocornut/imgui (ocornut)

stb: https://github.com/nothings/stb (Sean Barrett)

FFmpeg: https://ffmpeg.org (the FFmpeg developers, LGPL v2.1 or later) -
  the films: three DLLs beside the engine, loaded at run time and not
  compiled in; licence in Licenses\COPYING.LGPLv2.1, the source snapshot
  beside the release (FFmpeg-master.zip).

TRForge (MIT, TRForge contributors): five files are vendored (byte for
  byte but for three comment passages left out of Trg.h) and compiled into
  PCtomb5.exe - the reader for the remasters' LEVELn.TRG geometry and the
  helpers it needs. TRForge's own format descriptions are where several more
  of the HD path's rules come from; THIRD-PARTY.md's origin ledger names
  each, with this project's own count on the files. Licence and
  provenance: TOMB5 Code\TOMB5\vendor\trforge\.

discord-rpc: https://github.com/discord/discord-rpc (Discord, Inc.) - in
  the source tree as upstream TOMB5 shipped it, and switched off here:
  tomb5.cpp opens with TOMB5_DISCORD_RPC 0, so no call site is compiled.
  The project still hands the two prebuilt .lib to the linker, but with
  no symbol referenced nothing of them is pulled in - the shipped
  PCtomb5.exe carries no occurrence of the word Discord at all. Its
  notice travels all the same, because this project distributes the files.
  See THIRD-PARTY.md at
  the repository root for the licences and where each full text lives.
