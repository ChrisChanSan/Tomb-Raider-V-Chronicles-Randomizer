# Secret-Liste fuer den TR5 Randomizer.
#
# Dateiname = Autor_Kategorie.txt - der Autor erscheint so im Dropdown der
# jeweiligen Kategorie (Glitchless oder Glitched). Wer eine eigene Liste
# beisteuern will, legt einfach eine weitere Datei in diesen Ordner.
#
# Spalten:
#   Level             Dateiname des Levels
#   Anzahl            wie viele Secrets das Level hat (Gegenprobe)
#   Type_ID           223 = Secret
#   Level_ID          die Item-Indizes der Secrets im Vanilla-Level
#   New_Rooms/Sektor  wohin sie sollen, in derselben Reihenfolge wie Level_ID.
#                     Leer = dieses Level bleibt vanilla.
#   Extra_Options     zusaetzliche Items, Trigger und Geometrie. Mehrere
#                     Gruppen mit ";" trennen (eindeutig); das alte "+" wird
#                     weiter gelesen. Was der Leser nicht versteht, meldet er -
#                     ein vertipptes "@Angel0" verschwindet nicht stillschweigend.
#
#                     SECHS FORMEN:
#
#                     1) Item anhaengen
#                        add Type_ID(<Typ>)@Room<N>(x<A>,z<B>)
#                        Statt Raum+Sektor geht auch die Stelle eines
#                        vorhandenen Items:  @LikeItem(<Item>)
#
#                     2) Nur ein Trigger, ohne Item
#                        add Trigger_Type(Trigger)@Room<N>(x<A>,z<B>)
#                            to->... Item_Level_ID(<Ziele>)
#
#                     3) Vorhandenes Item umtypen
#                        replace Item_Level_ID(<Item>)with->Type_ID(<neuerTyp>)
#                        Ohne @Room bleibt die Stelle; MIT @Room(x,z) zieht das
#                        Item um (Sektormitte, Bodenhoehe gerechnet).
#
#                     4) Portal - versiegelte Wand beidseitig oeffnen
#                        Make_Portal@Room<A>(x,z)->Room<B>(x,z)
#                        Das "->" ist Paarung, nicht Richtung: EINE Zeile
#                        oeffnet beide Sektoren aufeinander. Das Sichtfenster
#                        muss im Level schon existieren, sonst Fehlermeldung.
#
#                     5) Kletterwand
#                        Make_Climb@Room<N>(x<A>,z<B>)@Angle(<Grad>)
#                        Winkel = Laras BLICK auf die Wand. Nur Viertel
#                        (0/90/180/270). Mehrere Zeilen auf demselben Sektor
#                        addieren ihre Richtungen.
#
#                     6) Raum bewaessern oder trockenlegen
#                        Make_Room_Water(<Raum>)   bzw.
#                        Make_Room_Nowater(<Raum>)
#                        Echter Eingriff: am Wasserbit haengen 44 Stellen im
#                        Motor (Schwimmen, Kamera, Sound, KI-Wege, Feuer).
#
#                     ZUSATZANGABEN (Form 1 und 3):
#                       @OCB(<Wert>)     Objektcode. Bei Schaltern bestimmt er,
#                                        wo Lara stehen muss!
#                       @Angle(<Grad>)   in GRAD, Klammern optional
#                       @Height(<Wert>)  so viele Einheiten HOEHER
#                       @XOff(<Wert>)    Versatz in X
#                       @ZOff(<Wert>)    Versatz in Z
#                     Nur Form 1:
#                       Trigger_Type(Key|Switch|Pickup)to->... Item_Level_ID(<Ziele>)
#
#                     Item_Level_ID nimmt MEHRERE Ziele, mit Komma getrennt.
#                     Ein Ziel ist ein vorhandener Itemindex oder "Neu<k>" -
#                     das k-te Item, das DIESE Zeile selbst anlegt. Damit
#                     laesst sich ein gerade erzeugtes Item ansteuern, dessen
#                     Index man beim Schreiben nicht kennen kann.
#
#                     Beispiel Doppeltuer, ein Schalter fuer beide Haelften:
#                       (replace Item_Level_ID(13)with->Type_ID(284)@Angle90)
#                       ; (add Type_ID(284)@LikeItem(13)@Height(1024)@Angle90)
#                       ; (add Type_ID(266)@OCB(8)@Room202(x1,z1)@Angle270
#                          +Trigger_Type(Switch)to->Door Item_Level_ID(13, Neu1))
#                       ; (Make_Portal@Room34(x0,z5)->Room36(x4,z5))
#
#                     Das "+" VOR Trigger_Type gehoert zur Gruppe und bleibt.
#
# STOLPERSTEINE, die im Spiel schwer zu finden sind:
#   - Schalter und Schluessellocher brauchen EBENEN Boden. Ihr Positions-
#     fenster ist in Y null breit; auf einer Schraege nimmt Lara viele Hoehen
#     an und trifft die eine nie. Alle 72 Vanilla-Schalter stehen eben.
#     Der Leser warnt, wenn Typ 258..274 auf einer Schraege landet.
#   - Falltueren muessen auf der Portalebene ihres Raums stehen (minfloor
#     bzw. maxceiling), sonst versiegeln sie nichts und Lara faellt durch.
#     Deckenfalltueren gehoeren in den UNTEREN Raum.
#   - Kein Wandgriff (OCB 2/9) in Gegnernaehe: der traegt ihn beim Sterben
#     davon, danach ist er nicht mehr aufnehmbar. Der Randomizer sperrt das
#     bei eigener Platzierung, in dieser Liste nicht.
#
# Die Hoehe wird nicht angegeben - der Randomizer rechnet die Bodenhoehe des
# Sektors selbst aus, auch auf Schraegen.
