Use the Setup.bat or the Steam function to set your resolution once
and have fun.

If you encounter bugs you can start the game via Log.bat. It writes a
logfile that will help with troubleshooting.


TWO FILES ARE MISSING AT FIRST, AND THAT IS CORRECT

Balance.txt and SecretRewards.txt do not come with this package. The
game writes both itself, next to PCtomb5.exe, THE FIRST TIME YOU START
IT. Until then they are simply not there - nothing is broken and
nothing is missing.

They are not shipped on purpose: the game reads its own defaults from
them, so a file delivered with the package would freeze today's values
on your installation forever, and later corrections to the balancing
would never reach you.

Balance.txt        every weapon's damage, every enemy's hit points,
                   every attack, every level hazard - and three
                   percentage lines that move all of it at once.
SecretRewards.txt  what each level hands over when you find all of
                   its secrets.

Both are plain text. Edit, save, restart the game. Deleting one brings
the defaults back - it is written again on the next start.

If you want to use the built-in language function you have to obtain
the corresponding language.DAT - some language.DAT's in the Steam
version are not working. You have to find a retail PC version of
"Tomb Raider (V) Chronicles".
