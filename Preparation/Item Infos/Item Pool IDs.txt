Generic items that can always be anywhere, no logic.
(Weapons, ammo, medipacks, generic pickups without room/trigger binding. Freely
swappable/randomizable as long as the OCB is normalized to 0 - see
project_tomb5_native_port.md, "CONFIRMED BUG": plinth/hidden OCB items (OCB 1/3/4/7/8)
become permanently uncollectable after GetCarriedItems() pickup by an enemy, because
DropBaddyPickups() does not reset the OCB on the drop. Randomizer rule: set all items in
this category to OCB 0 across the board.
ATTENTION: "normalize OCB to 0" applies ONLY to real pickup items (object_number = a
pickup object type). On enemy items (e.g. the Hydra) the OCB field has a completely
different, object-specific meaning - for the Hydra e.g. the position in the chain of 3,
see Enemy Pools.txt. Never run this rule blindly over all items in the level, always
filter by object_number first.)
